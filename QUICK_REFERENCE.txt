🔗 API ENDPOINTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. SAVE SENTIMENT (From ML Model)
   POST /api/v1/analysis/sentiment
   ──────────────────────────────────
   Body:
   {
     "videoUrl": "https://www.youtube.com/watch?v=...",
     "label": "positive",
     "score": 0.9425275325775146
   }
   Response: 201 Created
   
2. GET ALL SENTIMENTS (User's History)
   GET /api/v1/analysis?limit=20&skip=0
   ─────────────────────────────────────
   Response: Array of sentiment records with pagination

3. FILTER BY TYPE
   GET /api/v1/analysis/sentiment/positive
   GET /api/v1/analysis/sentiment/negative
   GET /api/v1/analysis/sentiment/neutral
   ─────────────────────────────────────
   Response: Filtered array of records

4. GET SINGLE RECORD
   GET /api/v1/analysis/:id
   ───────────────────────
   Response: Single sentiment record

5. DELETE RECORD
   DELETE /api/v1/analysis/:id
   ──────────────────────────
   Response: Success message

6. GET STATISTICS
   GET /api/v1/analysis/stats
   ──────────────────────────
   Response: Aggregated stats (count, avg score per sentiment type)

🚀 INTEGRATION WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. User submits video URL
2. ML model analyzes → produces sentiment output
3. Extract top sentiment (highest score)
4. POST to /api/v1/analysis/sentiment
5. Backend stores in MongoDB with timestamps
6. User can query results with GET endpoints
